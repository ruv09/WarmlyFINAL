# Warmly — Sprint 3

## Цель

Заменить временные эмодзи 🌳 на полноценные компоненты деревьев и подготовить систему для будущих дизайнерских иллюстраций.

---

## Важно

НЕ менять существующую архитектуру.

НЕ переписывать экран Mood.

НЕ менять Calendar.

НЕ менять Profile.

НЕ изменять существующую систему хранения.

НЕ обновлять зависимости.

---

# Что необходимо сделать

## 1. Создать компонент Tree

Файл:

components/forest/Tree.tsx

Компонент должен принимать объект дерева через props.

Например:

* mood
* x
* y
* treeType

---

## 2. Пока НЕ использовать изображения

Вместо этого нарисовать дерево средствами React Native.

Например:

* круглая зелёная крона;
* простой коричневый ствол.

Использовать View с borderRadius.

Главная задача — чтобы дерево уже было отдельным компонентом.

---

## 3. Цвет дерева зависит от настроения

Пока использовать спокойные оттенки.

Например:

😊 светло-зелёное

😌 тёпло-зелёное

🥰 золотисто-зелёное

😢 голубовато-зелёное

😡 тёмно-янтарное

😴 серо-зелёное

Важно:

Все деревья должны выглядеть красивыми.

Никакое настроение не должно выглядеть "хуже" остальных.

---

## 4. Размер дерева

Пока все деревья одинаковые.

Рост будет реализован позже.

---

## 5. ForestScene

ForestScene должен отображать список деревьев через компонент Tree.

Никаких эмодзи больше использовать не нужно.

---

## 6. Расположение

Использовать сохранённые координаты x и y.

Добавить небольшой отступ между деревьями.

Не располагать их строго по сетке.

---

## 7. Если деревьев нет

Продолжать показывать красивую заглушку.

---

## 8. Подготовка к будущим иллюстрациям

Компонент Tree должен быть написан так, чтобы позже вместо View можно было легко использовать SVG или PNG без изменения остальной логики.

---

# НЕ реализовывать

* рост деревьев;
* времена года;
* ночной режим;
* анимации;
* листья;
* цветы;
* светлячков;
* животных;
* масштабирование камеры.

---

# Результат

После выполнения задания пользователь должен увидеть настоящий лес из простых нарисованных деревьев вместо эмодзи.

Компонент Tree должен быть полностью готов к замене на дизайнерские иллюстрации в будущем.
