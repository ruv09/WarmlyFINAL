Проект: полноценное мобильное приложение на Expo React Native.

Цель:
Подготовить приложение к production-уровню и успешной модерации RuStore.

Основные задачи:

1. Исправить адаптивность интерфейса
2. Проверить корректность работы AI уведомлений
3. Сохранить текущий дизайн и архитектуру
4. Подготовить приложение под стабильную Android сборку

==================================================

================================

Комментарий модерации RuStore:

Нужно:

1. Проверить ВСЕ экраны приложения:

* маленькие Android устройства
* средние устройства
* большие экраны

2. Найти и исправить:

* fixed width
* fixed height
* absolute positioning, вызывающий выход элементов за экран
* overflow
* обрезание текста
* кнопки, выходящие за границы экрана
* элементы, прилипающие к краям

3. Исправить layout:

* использовать flex/flexGrow где необходимо
* заменить жесткие размеры на адаптивные
* сохранить существующий UI/UX
* не менять визуальный стиль приложения

4. Проверить:

* ScrollView
* SafeAreaView
* KeyboardAvoidingView
* padding/margin
* вложенные View
* FlatList/SectionList
* модальные окна

5. Проверить:

* формы
* поля ввода
* длинные тексты
* заголовки
* кнопки
* popup/modals

6. Android:

* исключить наложение на системные элементы
* исключить выход за экран
* обеспечить одинаковое отображение на разных диагоналях

7. Проверить screenshots для RuStore:

* формат 9:16
* отсутствие обрезания
* корректное отображение интерфейса

==================================================
ЧАСТЬ 2 — AI СИСТЕМА ПОДДЕРЖКИ
==============================

Нужно реализовать внутреннюю AI систему генерации поддерживающих сообщений.

ВАЖНО:
Пользователь НЕ общается с AI.
Никакого чата с AI в приложении быть не должно.

Логика:
AI работает полностью в фоне.

Как это должно работать:

1. Один раз в день AI генерирует короткую поддерживающую фразу
2. Приложение автоматически отправляет push уведомление
3. Пользователь получает готовый текст

Примеры:

* «Все обязательно наладится»
* «Ты справляешься лучше, чем думаешь»
* «Сейчас сложный период, но он пройдет»

==================================================
ТРЕБОВАНИЯ К AI
===============

1. Генерация:

* короткие сообщения
* теплый человеческий стиль
* без токсичной позитивности
* без повторов
* естественный русский язык

2. Ограничения:

* не использовать медицинские советы
* не использовать психологические диагнозы
* не использовать опасные формулировки
* не упоминать суицид/депрессию/лечение
* не давать жизненные инструкции

3. Категории сообщений:

* поддержка
* спокойствие
* мотивация
* восстановление
* эмоциональное тепло
* забота

==================================================
ЧАСТЬ 3 — PUSH УВЕДОМЛЕНИЯ
==========================

Нужно реализовать стабильную систему push уведомлений.

Требования:

1. Уведомления приходят автоматически

2. Только в промежутке:
   08:00 — 22:00
   по локальному времени пользователя

3. Проверить:

* корректную работу timezone
* чтобы уведомления не приходили ночью
* чтобы расписание сохранялось после перезапуска приложения
* чтобы уведомления не дублировались

4. Если пользователь долго не открывал приложение:

* уведомления все равно должны работать

5. Проверить Android push behavior:

* foreground
* background
* killed app state
