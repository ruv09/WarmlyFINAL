# assets

Статические ресурсы: шрифты (`fonts/`) и изображения (`images/`).
Иллюстрации деревьев появятся здесь, когда будет готов визуальный дизайн —
до этого момента `components/tree/TreeIllustration.tsx` рисует деревья
через `react-native-svg` по виду (`TreeSpecies`), без стадий роста
(см. `/FOREST.md`).
