# screens

Экраны — точки входа для маршрутов Expo Router (`app/*.tsx` будут
импортировать компоненты отсюда). Экран отвечает за композицию:
берёт данные из `hooks`, передаёт их в `components`.

Правила:
- Экран не обращается к `services` и `store` напрямую — только через `hooks`.
- Бизнес-правила (например, "запись создаёт дерево") в экране не пишутся —
  они уже инкапсулированы в `store`.

Пока не реализовано — согласно текущему этапу разработки.
