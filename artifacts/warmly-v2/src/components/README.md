# components

Переиспользуемые, не привязанные к конкретному экрану UI-компоненты
(кнопки, карточки, поля ввода, элементы леса и т.д.).

Правила:
- Компонент получает данные и колбэки через props, не обращается
  к `store` или `services` напрямую (кроме `useTheme` из `src/theme` для оформления).
- Компонент не знает, на каком экране он используется.
- Для анимаций компонент использует готовые обёртки из
  `src/components/animation` (`FadeView`, `ScaleView`, `SlideView`,
  `PressableScale`) или хуки из `src/animation` — не создаёт свои
  `Animated.Value` и не задаёт длительности/кривые вручную. См. /ANIMATION.md.

Пока не реализовано — согласно текущему этапу разработки
(сначала фундамент, потом UI).
