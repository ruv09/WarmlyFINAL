# Лес — каталог записей

Экран «Лес» — визуальный каталог дневника. Одна запись = одно дерево.
Свободной карты, камеры, joystick и pinch больше нет.

## Поток

1. Пользователь открывает **Лес** и видит вертикальный каталог.
2. Деревья сгруппированы по месяцу даты записи (`entry.date`).
3. Сначала самый новый месяц, внутри месяца — новые записи выше.
4. Тап по дереву открывает статичную сцену: атмосфера леса + это дерево + табличка.
5. Назад возвращает в каталог на той же позиции скролла (каталог не размонтируется).

## Данные

Лес не хранит отдельную сущность «месяц». Группировка считается из записей:

- `src/services/forest/catalog.ts` — `groupForestByMonth`, `layoutMonthGrove`
- вид дерева назначается при создании записи: `assignNextSpecies`
- `entry.treeId` однозначно указывает на PNG из `assets/trees/`

Удаление записи удаляет связанное дерево. Редактирование текста не меняет вид.

## UI

- `ForestCatalog` — виртуализированный список месяцев (`FlatList`)
- `TreeGroveScene` — статичная сцена просмотра
- `ForestAtmosphere` — существующая пастельная атмосфера без параллакса от жестов
