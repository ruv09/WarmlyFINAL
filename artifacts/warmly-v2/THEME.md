# Движок темы

Единая система визуальных токенов: светлая тема, тёмная тема, системная
тема, и пять категорий централизованных значений — цвета, типографика,
отступы, радиус скругления, длительности анимаций.

## Структура папки

```
src/theme/
  tokens/
    colors.ts        Палитры: ColorPalette, lightColors, darkColors
    typography.ts     Размеры, начертания, межстрочный интервал,
                        лимиты масштабирования шрифта
    spacing.ts          Шкала отступов + адаптивный множитель под устройство
    radius.ts            Радиус скругления
    animation.ts           Длительности и кривые анимации
    index.ts                 Barrel-экспорт всех токенов

  types.ts            Theme — форма объекта, которую получает компонент
  useTheme.ts          Хук, который разрешает и собирает Theme
  index.ts              Публичный barrel: `import { useTheme } from "@/theme"`
```

## Почему `theme/`, а не всё в `constants/`

До этого шага цвета, отступы и типографика лежали в `constants/`
вперемешку с вещами, которые визуальной темой не являются: каталогом
настроений, ключами AsyncStorage, маршрутами навигации. Формально
"централизовано", но по факту — источник истины для темы был размазан
по нескольким файлам одной директории вместе с несвязанными данными.

`src/theme/` — выделенный модуль ровно под требование задачи: пять
категорий токенов, ничего лишнего. `constants/` теперь содержит только
то, что темой не является:

```
src/constants/
  moods.ts          Каталог настроений (продуктовые данные)
  storageKeys.ts     Ключи AsyncStorage
  treeGrowth.ts       Пороги роста дерева (продуктовая логика, не тема)
  routes.ts            Реестр путей навигации
  layout.ts             Брейкпоинты и классификация устройства
                          (используется темой для адаптивных отступов,
                          но сама по себе — про устройство, не про стиль)
```

Разделение простое: если значение меняется при смене темы оформления —
оно в `theme/`. Если нет — в `constants/`.

## `tokens/` — данные без React

Все файлы в `tokens/` — чистые данные и чистые функции, без единого
хука и без импорта `react-native`. Это осознанно: токены должны быть
пригодны для использования где угодно, включая, например, юнит-тесты
`treeGrowthService` или конфиг для сторонних инструментов (условный
дизайн-токен экспорт), без необходимости рендерить React-дерево.

## `useTheme()` — единственная точка доступа

```ts
const theme = useTheme();
// theme.colors.textPrimary
// theme.typography.sizes.body
// theme.spacing("md")
// theme.radius.md
// theme.animation.durations.fast
```

Компонент не имеет способа получить цвет, отступ, размер шрифта или
длительность анимации в обход этого объекта — `theme/tokens/*` не
экспортируются напрямую туда, где пишутся компоненты (`src/components`,
`src/screens`); только через `useTheme()`. Это и есть буквальное
выполнение требования "no hardcoded values inside components": в коде
компонента физически негде взять голое число или hex-строку, если
следовать этому правилу — только `theme.*`.

`useTheme()` разрешает тему из трёх источников:

1. **Настройка пользователя** (`light` / `dark` / `auto`) —
   `src/store/useSettingsStore`.
2. **Системная тема устройства** — `useColorScheme()` из React Native,
   участвует только когда выбран режим `auto`.
3. **Метрики устройства** (`useDeviceMetrics`) — для адаптивных
   отступов и ширины колонки контента; подробное обоснование
   адаптивной части — в `/RESPONSIVE.md`, здесь это используется,
   а не переопределяется.

## Почему длительности анимации — тоже токены

Без централизации разные экраны неизбежно получают анимации разной
"скорости" на глаз: 200ms в одном месте, 300ms в другом — просто
потому что так написалось в моменте, без сознательного решения.
`theme.animation.durations` даёт четыре именованных шага (`instant`,
`fast`, `base`, `slow`) вместо голых чисел, и `theme.animation.easing`
— три именованные кривые. Формат кривых (контрольные точки Безье) —
данные, не привязанные к конкретной анимационной библиотеке: подойдут
и для `Animated.Easing.bezier` из React Native, и для
`react-native-reanimated`, когда до анимаций дойдёт очередь.

Отдельно зафиксировано (как требование к будущей реализации, не как
код — анимируемых компонентов в проекте пока нет): при реализации
анимаций компоненты обязаны учитывать системную настройку "уменьшить
анимацию" и заменять анимацию на мгновенный переход, а не просто
ускорять её — это соответствует общей философии приложения как
спокойного, ненавязчивого пространства.

## Пример: почему нельзя "просто быстро" захардкодить цвет

Если в будущем компоненте написать `backgroundColor: "#FFFFFF"` вместо
`theme.colors.surface` — это будет работать в светлой теме и сломается
в тёмной (белый фон на тёмном экране). Централизация токенов не
стилистическое предпочтение, а единственный способ, которым тёмная
тема в принципе может существовать без дублирования каждого экрана в
двух версиях.

## Обновление палитры под визуальный референс

Светлая и тёмная палитры (`theme/tokens/colors.ts`) приведены в
соответствие с художественными референсами: светлая — визуальная
концепция "Природный уют" (тёплый кремовый фон, мягкий зелёный
акцент), тёмная — объединение "Сказочный лес" и "Тёплый вечер" в одно
ночное настроение (глубокий сине-фиолетовый фон, тёплый золотистый
акцент вместо второй, отдельной тёмной темы — в приложении их может
быть только две, light и dark).

Добавлены два новых токена палитры:
- **`accentWarm`** — тёплый акцент (огоньки, ягоды, акценты
  статистики), отдельно от `accent` (зелёный — "рост, жизнь леса").
  Разделение осознанное: смешивать "цвет роста" и "цвет тепла" в один
  токен означало бы терять смысл при будущих правках палитры.
- **`overlay`** — полупрозрачная подложка для текста поверх
  иллюстрированного хрома поверх леса, чтобы текст оставался
  читаемым на любом фоне.

Также добавлен `radius.xl` (32) — для крупных иллюстрированных
карточек, где обычный `radius.lg` смотрелся мельче, чем в референсе.

## Что проверено

`npx tsc --noEmit` проходит без ошибок. Старые файлы
(`constants/theme.ts`, `constants/spacing.ts`, `constants/typography.ts`,
`hooks/useAppTheme.ts`) удалены — токены существуют ровно в одном
месте, без дублей на переходный период.
